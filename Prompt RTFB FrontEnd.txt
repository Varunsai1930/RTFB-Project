1. Project Identity & Purpose
The product is called InvisiWork. It solves a real problem in software engineering teams — developers do enormous amounts of invisible work (code reviews, mentoring, documentation, meetings, planning) that never gets tracked, never appears in sprint boards, and never gets recognized in performance reviews. InvisiWork makes this invisible work visible, measurable, and impactful. It serves two user types: Developers (who log and view their own work) and Managers/Team Leads (who view team-wide analytics and compare productivity metrics). A System Scheduler actor also exists — represented in the UI as auto-refresh indicators.

2. Tech Stack — Hard Constraint

Pure HTML5, CSS3, and ES6+ Vanilla JavaScript only.
Absolutely no React, Vue, Angular, or any JS framework.
No CSS frameworks — no Bootstrap, no Tailwind. All styling hand-crafted using CSS custom properties, Flexbox, and CSS Grid.
No jQuery. No external UI libraries.
Use Inter font from Google Fonts.
Use mock/hardcoded JavaScript data to simulate all real data — no API calls.
All pages must be fully responsive: mobile-first, tablet, and desktop breakpoints.

5. Backend API Endpoints
Auth Blueprint (/api/auth):
	•	POST /register — create user, hash password with bcrypt, store in MySQL.
	•	POST /login — verify credentials, return JWT token.
	•	POST /logout — invalidate session.
Activities Blueprint (/api/activities):
	•	POST /log — receive activity log (category, description, duration, user_id), classify it, store in MongoDB, sync to Google Sheets.
	•	GET /list — return paginated activity list for current user. Supports filter by category and date range.
	•	GET /classify — auto-classify a description string into a category using keyword matching logic in Python.
Dashboard Blueprint (/api/dashboard):
	•	GET /personal — return personal KPI data (today's tasks, weekly hours, reviews done, impact score) computed via Pandas from MongoDB.
	•	GET /weekly — return week's activity data grouped by day. Accepts ?week= param.
	•	GET /team — return team-wide aggregated metrics (Manager/Team Lead only).
Analytics Blueprint (/api/analytics):
	•	GET /iwr — calculate and return IWR score (Invisible Work Ratio) using SciPy statistical methods.
	•	GET /pii — calculate and return PII score (Personal Impact Index) using Pandas aggregation.
	•	GET /burnout — calculate burnout correlation score using scipy.stats.pearsonr on activity patterns vs. overwork indicators.
	•	GET /chart/activity-breakdown — return Plotly chart JSON for activity breakdown.
	•	GET /chart/weekly-trend — return Plotly chart JSON for weekly trend.
Sheets Blueprint (/api/sheets):
	•	POST /sync — pull latest data from Google Sheets, convert to DataFrame, upsert into MongoDB.
	•	GET /status — return last sync timestamp and row count.
All routes: try/except error handling. Return {"error": "...", "status": 400} on failure. Enable CORS. Use python-dotenv for all config.

6. Data Processing Pipeline In data/processor.py:
	•	clean_activities(df) — handle nulls, type casting, duplicate removal using Pandas.
	•	compute_weekly_stats(df) — group by day, sum durations, count activities using Pandas + NumPy.
	•	compute_iwr(df) — ratio of invisible work hours to total logged hours. Use NumPy for computation.
	•	compute_pii(df) — weighted impact score across categories using NumPy weighted average.
	•	compute_burnout_correlation(df) — Pearson correlation between daily hours logged and days-since-last-break using scipy.stats.pearsonr. Return correlation coefficient + p-value.
	•	All functions: accept a Pandas DataFrame, return a dict or DataFrame. Never modify input in place.

7. Visualization Layer
	•	matplotlib_charts.py: generate_activity_pie(df) → saves PNG to /static/charts/. generate_weekly_bar(df) → saves PNG.
	•	plotly_charts.py: get_activity_breakdown_json(df) → returns Plotly JSON. get_weekly_trend_json(df) → returns Plotly JSON. Use plotly.express for simple charts, plotly.graph_objects for full control. Always include axis labels, title, legend.
	•	dash_app.py: Dash app mounted at /analytics/dashboard. Modular layout. Callbacks in separate functions. Embeds Plotly charts interactively.
